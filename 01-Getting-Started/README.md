# 01 — Getting Started

Minimal Flask application with a single route that returns plain text.

## Run

```bash
cd 01-Getting-Started
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r ../requirements.txt
python app.py
```

Open http://127.0.0.1:5000/ — you should see `Hello, Blog!`.
