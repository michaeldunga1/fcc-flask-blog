# 06 — Posts

Full CRUD for posts: create, view detail, edit, and delete. Only the post owner can change or remove it.

## Run

```bash
cd 06-Posts
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r ../requirements.txt
python app.py
```

Register, publish a post, open its detail page, then try edit and delete as the owner.
